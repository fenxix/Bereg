Тихий Берег — запуск в Windows
1. Дважды щёлкните start-game.bat.
2. Сервер откроет игру в браузере по адресу http://localhost:4173
3. Не закрывайте чёрное окно, пока играете. Чтобы остановить сервер, закройте окно.
Установка Node.js не нужна: используется встроенный Windows PowerShell.
Не открывайте index.html напрямую — браузер блокирует ES-модули на file://

В этой версии город заполнен новыми домами и улочками; жители ходят по индивидуальным распорядкам, полицейская гонится за двумя карманниками, по улицам ездят велосипедисты и скейтеры. В саду летают бабочки и живут жуки с гусеницами. Масштаб угловой и большой карты общий и сохраняется.

План острова этой версии: центральная площадь, жилые улочки, рынок, ферма и цветочный сад, лес, маяк, бухта и пирс. NPC следуют общей дорожной сети и обходят препятствия. Насекомые и ракушки появляются в подходящих зонах острова, а мини-карта снова компактная.
