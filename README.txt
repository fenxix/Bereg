Тихий Берег — запуск в Windows
1. Дважды щёлкните start-game.bat.
2. Сервер откроет игру в браузере по адресу http://localhost:4173
3. Не закрывайте чёрное окно, пока играете. Чтобы остановить сервер, закройте окно.
Установка Node.js не нужна: используется встроенный Windows PowerShell.
Не открывайте index.html напрямую — браузер блокирует ES-модули на file://
